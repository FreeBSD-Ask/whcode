# UI 设计规范

**日期**： 2026-10-21 | **对应需求**： FR-601、FR-612、FR-613、FR-615、FR-617、FR-618 | **关联**： ADR-014、`gui-suspend.md`

## 1. 设计目标与约束

| 约束 | 含义 | 设计后果 |
|---|---|---|
| 墨水屏 | 刷新慢（整屏 2—4 秒级）、黑→白转换残影最重 | 白底黑字优先；避免大面积黑白翻转；避免周期全刷；局部更新 |
| A 屏 / AMOLED | 仅纯黑 `#000000` 关断像素；静态高亮会烧屏 | 夜间主题纯黑；无固定高亮闪烁元素；无大面积高饱和色 |
| 低内存 / 低 CPU | 单会话不叠加固定开销（FR-614） | 无框架、无动画、无大图；文本流式渲染 |
| 国际化 | zh-CN / en 双语文案；RTL 预留 | 文案键化；布局不假设 LTR |
| 安全 | 密钥与令牌永不显示 | 追踪默认 `redacted`；`full` 需显式警告 |

## 2. 信息架构（六区）

| 区域 | 内容 | 数据来源 | 刷新策略 |
|---|---|---|---|
| 会话树 | 会话列表、归档状态、当前会话 | 应用服务快照 | 事件驱动 |
| 任务 | 阶段分布、完成度、阻塞、活跃任务 | 快照 + 事件 | 事件驱动（脏标记） |
| 上下文 | 预算、装入来源、截断原因 | `context` 契约 | 请求时拉取 |
| 事件 | 最近事件尾部 + 游标 | 事件流（关键事件不合并） | 增量追加 |
| Spec 状态 | 阶段、门禁结果、产物版本 | 快照 | 事件驱动 |
| diff 预览 | 变更摘要（文本 diff） | 产物引用 | 按需 |

**键盘优先**：`j/k` 或方向键移动、`Enter` 打开、`/` 搜索、`q` 退出、`Ctrl-C` 退出；
所有操作在无鼠标时可达。CUI 与 Web 必须提供等价业务能力（ADR-009），交互形态可不同。

## 3. 主题（精确色值）

| 主题 | 背景 | 前景 | 强调 | 用途 |
|---|---|---|---|---|
| `amoled-night`（A 屏夜间） | `#000000` | `#E6E6E6` | 边框 `#3A3A3A`，选中反显 | 夜间、OLED |
| `eink-day`（墨水屏日间） | `#FFFFFF` | `#000000` | 仅用线框与下划线，不用填充色 | 白天、墨水屏 |
| `eink-night`（墨水屏夜间） | `#000000` | `#FFFFFF` | 线框 `#FFFFFF` | 夜间、墨水屏 |

规则：

- 禁止“近黑/深灰”作为夜间背景（深灰仍耗电；OLED 只有纯黑关断）；
- 状态不得只用颜色区分：必须叠加符号或文字（例如 `[!] blocked`、`[✓] completed`）；
- 不做渐变、阴影、模糊；边框单线；选中态用反显或 `>` 前缀。
- 主题通过配置选择（`ui.theme`），并可用环境变量覆盖；默认 `eink-day`（最保守、最省电）。

## 4. 排版与尺寸

- 字体：等宽系统字体栈（不加载第三方字体）；CJK 宽度按 2 列计算，截断按显示宽度而非字节；
- 行宽：TUI 目标 ≤ 100 列（与 `rustfmt` 一致的可读性）；超宽内容折行而非横向滚动；
- 间距刻度：0 / 1 / 2 列（无 0.5 像素概念）；不做像素级精细布局；
- 列表：游标分页（禁止无限滚动），每页固定条数，页首显示游标与总数（若可得）。

## 5. 墨水屏细则

1. **减少全屏刷新**：只在数据变化区域重绘（脏矩形/脏标记）；状态栏不动则不重绘；
2. **避免黑白大翻转**：不做整屏反色切换；主题切换需用户显式操作并提示“会触发全刷”；
3. **残影管理**：连续局部更新 N 次后（可配置，默认 20）提示或执行一次全刷；
4. **无动画**：进度用文本百分比或步骤文字，不用进度条动画；
5. **无光标闪烁**：输入区用静态提示符 + 光标位置标记。

## 6. 极简前端预算（Web，FR-618）

| 项 | 上限 | 说明 |
|---|---|---|
| 首屏 JS（gzip） | 50 KB | 原生 ES modules，无框架 |
| CSS（gzip） | 20 KB | 单文件 + CSS 变量主题 |
| DOM 节点 | ≤ 2 000/页 | 长列表分页 |
| 第三方字体 | 0 | 系统字体栈 |
| WebGL / Canvas 动画 | 0 | 禁止 |
| 自动播放媒体 | 0 | 禁止 |

校验脚本：`ci/benchmarks/check-frontend-budget.py`（T137 交付，超预算即 CI 失败）。

## 7. 国际化与 RTL

- 文案键：`i18n/<locale>/<domain>.po`；键名语义化（`session.archive.confirm`），不嵌 UI 文案；
- 复数与性别：使用 gettext `ngettext` 语义；不得用字符串拼接复数；
- RTL（阿拉伯语等）：
  - 布局方向由 `dir` 决定（`ltr`/`rtl`），TUI 侧预留 `text_direction` 接口；
  - 图标与箭头镜像；数字与代码片段保持 LTR（双向文本隔离符）；
  - 边框与对齐随方向翻折，不硬编码“左/右”语义。
- 回退链：`zh-CN → en → 键名`；缺失翻译必须显示键名并记录（不得显示空白）。

## 8. 可访问性

- 对比度：纯黑/纯白组合满足 WCAG AAA；灰阶仅用于次要信息且不低于 4.5:1；
- 键盘可达：所有交互可键盘完成；焦点可见（反显或 `>` 标记）；
- 无动画模式：`prefers-reduced-motion` 或配置关闭后不创建任何动画定时器；
- 屏幕阅读器（Web）：语义化标签、`aria-live` 仅用于关键状态（避免刷屏）。

## 9. 最小化与挂起（FR-617）

见 `docs/guides/gui-suspend.md`：不可见时停止绘制/动画/轮询；恢复时先取快照再一次全量重绘；
TUI 在窗口最小化时跳过绘制但继续记账关键事件。


## 11. 自由、主体性与暗黑模式

- 退出、导出与离线使用入口始终可见，不得藏到三级菜单或仅联网可见；
- 不预选付费/订阅/遥测，不隐藏取消按钮，不做虚假紧迫感与恐吓式安全提示；
- 不做排行榜、连胜、签到、推送轰炸等成瘾机制；
- 默认值可见、可改、可撤销；用户拒绝某功能后不得反复纠缠；
- 失败提示指向可执行下一步，不评价用户人格；
- 安全提示必须给出威胁与代价，不以“最佳实践”要求用户服从。

## 10. UI 验收清单

- [ ] 三套主题色值精确（`#000000` / `#FFFFFF`），可配置切换
- [ ] 状态不依赖颜色单独表达
- [ ] 无动画、无自动播放、无第三方字体
- [ ] Web 预算达标（JS/CSS/DOM）
- [ ] 无 JS 时只读视图可用
- [ ] zh-CN 与 en 文案齐备；缺失回退 en 并可见
- [ ] RTL 布局可切换且不破版
- [ ] 最小化/还原 20 次无内存增长与崩溃

# 标准基线（单一事实源）

**建立**：2026-11-14（ADR-072；研读证据 `research/standards-alignment/`） | **强制级**：本文件是“本仓承认哪些标准、什么版本、作何判定”的唯一出处；其他文档引用标准时链接到这里，不各自登记版本

**口径**：

1. 版本事实以标准组织官方页为准（ISO.org／IEEE SA／Open Group／NIST／openstd.samr.gov.cn），每年至少复核一次；上游换版即复审对应行。
2. 本仓不宣称任何合规或认证；安全关键类（IEC 61508、ISO 26262、DO-178C／DO-330、ISO/SAE 21434）只作思想参照，不对标。
3. 判定五类：已覆盖／部分覆盖／缺口／有意偏离／不适用；逐域细节见 `research/standards-alignment/matrix.md`（研究证据，不承载承诺）。
4. 门禁：`python .github/scripts/check-standards-baseline.py`（结构检查：本文件登记行六字段齐全、判定取值合法、停用登记节在场；`--strict` 另查已停用标准裸引用，SDK 批次落账后评估接入 CI）。

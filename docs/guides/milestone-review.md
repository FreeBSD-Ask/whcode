# 里程碑评审协议（Agent Work Loop 评审层）

**状态**：已批准（2026-10-29，建议书 D2，`research/synthesis/proposal.md`）| **来源研究**：
`research/better-harness/`（commit `b605532`）、`research/synthesis/README.md`（交叉发现 1/2/6/8/10）

本指南定义 WHCode 里程碑（M 收口、ADR 立项、能力批次完成）时的**评审协议**：把项目、
事件与会话证据转为证据约束的发现，发现再经既有门禁流程（任务/Check/ADR）落地。
它**不替代** G0—G5 门禁，也不新增状态机——评审输出恰好是 `tasks.md`/`checklist.md` 的
输入源之一。

## 1. 铁律（先于一切步骤）

1. **LLM 判定仅 advisory**：发现筛选、严重度、证据态升级建议由评审代理给出；Check 勾选、
   证据态修改、任务状态变更的**判定权归复核人与程序门禁**（AGENTS.md §5、ADR-046 §2.6）。
   可判定部分（计数、校验、扫描、链接图）一律程序化。
2. **配置的能力不是被观测的使用**：静态机制最多登记 `present`；只有关联到任务的执行留痕
   才能支持 `exercised` 及以上（ADR-046 状态枚举）。
3. **不可判定必须显式**：证据不足时保留 `unobserved`/`missing`，不得用聚合计数、文件名、
   资产存在性、运行时长填充结论（区分正确的空与错误的空，
   `docs/guides/signal-chain-completeness.md`）。
4. **评审是用户显式触发的里程碑操作**：不做定期自动评审；每次评审的资源代价（模型调用
   次数）在评审记录中登记。

## 2. 协议五步

### 步骤 1：冻结证据包

确定性收集，无模型参与：`cargo doctor`/`bench baseline`、`traceability.py`、
`check_counts.py`（含 ADR-046 证据态分布）、git 有界历史（窗口与本里程碑一致）、
密钥扫描。输出固定为一份证据包清单（命令 + argv + 退出码 + 关键计数），事件追踪
保持 `redacted`。收集器失败不得用模型推断补齐——缺失收集器输出登记为 `unobserved`。

### 步骤 2：并行独立证据收集（硬上限 3 个代理）

按三个**互不传递结论**的证据域并行（每域恰好一个只读子代理，禁止再委托）：

| 域 | 输入 | 禁止 |
|---|---|---|
| 会话/事件证据 | 本里程碑事件表导出（redacted 语义切片） | 读原始凭据、未脱敏载荷 |
| 项目 Harness 证据 | 步骤 1 证据包 + 有界 diff/历史 | 执行写操作、启动进程 |
| 代理资产证据 | AGENTS.md/specs/ADR/guides 清单与完整性 | 把清单存在当作用 |

每个子代理产出 3—5 条**候选**发现（候选不是结论，不定严重度）。

### 步骤 3：调和与冻结

主代理一次调和：保留全部候选；只合并"同目标、同观察后果、同 owner、同修复路线"的
候选；每个被弃候选留一句理由；**先冻结发现清单与证据态建议，再做任何排序**。
每条合格发现必须四要件齐备：被检视的缺口、有界影响、最小 owner 对齐修复、验证路线。
计数、文件名、资产存在性、严重度、年龄单独不构成发现。

### 步骤 4：质量门（渲染/登记前逐条过）

1. 证据资格：观察后果、显式治理要求或确定性缺陷；相似性/缺席/理论风险只是线索；
2. 读者价值：标题指名观察后果，不指名内部概念；事实/推断/不确定分写；
3. 事实一致：所有计数出自同一证据包；
4. 资产问责：清单存在不证明选择/使用/有用/结果；
5. 隐私：无密钥、无未脱敏载荷、无会话标识（FR-203、D-05）；
6. 可执行修复：修复命令必须已在证据包中发现，外部写操作列授权前置；
7. 分数纪律：同窗修复不得宣称长期有效（Loop Effectiveness 类结论必须等可比后期证据）。

### 步骤 5：落地与后续

- 合格发现 → 登记为 `tasks.md` 新任务或 `checklist.md` 新 Check（走既有 G1 追溯）；
- 证据态建议 → 提交复核人确认后由人写入（ADR-046）；
- 修复验证 → 独立复核（新代理或人工），结论三值：verified/partial/blocked，只更新
  修复进度，**不得同窗提升 Check 证据态到 `outcome-supported`**；
- 复发信号（≥2 个可比里程碑出现同类发现）→ 触发学习回路：按最小持久所有者路由
  （指南/门禁脚本/ADR > 新流程），禁止默认新增文档。

## 3. 评审记录

每次评审在 `artifacts/reviews/<里程碑>-review.md` 留痕：证据包清单、三个证据域的
候选汇总、冻结后的发现清单（含四要件与证据态建议）、质量门结论、落地项（任务/Check
编号）、模型调用次数。`artifacts/` 为忽略目录 + 白名单例外机制，评审记录入库须在
`.gitignore` 增补对应 `!/artifacts/reviews/...` 例外。记录归 G4 验收证据口径（ADR-037）。

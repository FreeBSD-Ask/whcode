# Windows 11 amd64 兼容矩阵与已知限制（T118）

**版本**：`0.1.0`（M9 工程侧基线，未发布） | **更新**：2026-10-23

## 1. 平台支持

| 平台 | 状态 | 依据 |
|---|---|---|
| Windows 11 amd64（`x86_64-pc-windows-msvc`） | **唯一验收目标**，已验收（M0—M9 测试在本机通过；2026-10-23 进度复核后 `fmt`/`clippy`/`test`/契约/布局门禁全绿） | ADR-013 |
| FreeBSD / NetBSD | **延后**：代码级兼容（交叉类型检查通过），无原生构建与运行证据 | ADR-013、T020/T021 |
| OpenBSD / DragonFly BSD | **延后**：移出原生目标，改由内置 SSH 客户端控制 | ADR-011/013 |
| 32 位平台 | **不支持** | ADR-013 |

## 2. 已知限制（M9 时点）

1. **性能预算已在 Windows 11 amd64 冻结**（ADR-025，2026-10-23）：NFR-208 概览 p95
   实测 6 071 µs（≤ 50 ms）、NFR-210 写入吞吐中位数 6 921 条/秒（≥ 2 000 条/秒）；
   其余八项**保持候选**并登记责任人与退出条件；BSD 无运行证据，不参与冻结；
   72 小时时间序列未取得（T116 阻塞）。
2. **稳定性测试未运行**（T116）：24 小时（候选发布 72 小时）长跑未执行，
   NFR-204 长时泄漏斜率未测量。
3. **真实 LLM Provider 未接线**（M3/T056 桩交付）：HTTP Provider 属后续接入；
   桩的取消语义为“下个 chunk 前生效”（§8.4 既定说明）。
4. **M7 BSD SSH 服务端延后**（ADR-013）：`serve --ssh` 命令语义属 M7；已交付的只有
   内置 SSH **客户端**原型（公钥认证、受限命令、超时与输出上限、意图—执行—登记留痕）。
5. **验收检查点：249 项全部有复核记录，209 通过 / 40 未通过**（2026-10-23 逐条复核 +
   里程碑批次补录）。
   未通过项含 M7 延后、M8 的 JS/Python/GitBash 引擎与 ABI 记录未接入、V-304 用例缺失、
   预算十项中八项未测与 72 h 序列缺失、WS 广播未实现、CI 未接线、发布包与三份指南缺失。
   TUI 六视图、Web UI（含会话/任务/清理/运行时写命令）、CUI 命令树与 SDD 门禁
   已有实现与实测记录（对应判据多已通过）；运行时目前只有接口与门控，引擎未接入
   ——**实现完成不等于验收通过**，对外表述不得混淆两者。
6. **V-003 交互四项 / V-004 服务端验收**：人工证据未取得（M0 报告阻塞项）。
7. **DuckDB 单文件持久化**（ADR-001）：`memory_limit` 默认 192MB（§5.4 基线），
   不代表进程 RSS（NFR-201—204）。
8. **无原生 GUI，且禁止浏览器套壳**（ADR-026，铁律）：当前桌面形态只有 TUI（终端），
   Web UI 是**独立浏览器前端**。桌面 GUI 若实现必须原生（原生控件或自绘），
   不得以内嵌浏览器引擎（WebView／WebView2、CEF、Tauri／wry、Electron、NW.js）承载，
   “自绘窗口 + 内嵌 Web UI”同样禁止；GUI 尚无 FR，须先立需求与 ADR。

## 3. 发布包构成（§12.2）

- 二进制：`whcode`（`whcode-bin`，MSVC 构建，Windows 11 amd64）；
- DuckDB 动态库：`vendor/duckdb/1.5.6/duckdb.dll`（SHA256 校验，`ci/fetch-duckdb.py`）；
- 许可证：BSD-2-Clause（版权主体 FreeBSD 中文社区）；
- 工具链锁定：Rust 1.99.1（`rust-toolchain.toml`），MSVC 14.44（不使用 GNU 工具链）。

**发布判据**：强制验收（V-001—V-307 中已实现部分）全通过 + 本限制清单随包发布；
预算冻结与长时稳定性未达成前**不发正式版本**（预发布标识 `v0.1.0-m*`）。

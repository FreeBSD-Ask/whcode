# ADR-008：运行时均在子进程中执行

- **状态**：已批准（M0 批准，2026-10-21；tasks.md T029 / V-007）
- **来源**：任务书 §2（原状态"必须冻结"）、§1.3、§10.2
- **责任人**：运行时负责人
- **退出条件**：M8 完成 V-301—V-307，并留存“默认关闭全部运行时 feature”的构建与运行证据（FR-704）
- **批准依据**：`crates/whcode-runtime/Cargo.toml` 的 `[features] default = []` 已落实；`contracts/runtime-protocol.md` 与正文约束一致；运行时行为未在 M0 验证。

## 决策

所有脚本运行时（JavaScript、Python、Shell 及 Windows Git Bash payload）**均在受控子进程**中
执行；主进程不得直接嵌入不受信任脚本执行。

## 理由与约束

限制崩溃、泄漏与脚本资源使用对主进程的影响；范围外事项包含"把任意不受信任脚本在主进程内执行"
（§1.3）。约束：子进程默认继承最小化环境变量集合；受超时、输出上限、取消与可用资源限制约束；
平台不具备可靠内存限制能力时必须报告"无法强制限制"；未启用运行时不加载动态库、不占端口、
不注册工具（FR-704）。

## 替代方案

- 主进程内嵌引擎（Boa/RustPython 直接链接）：崩溃与资源失控直接影响核心流程，被 §1.3 与本节否决。
- 动态链接 `libpython` 视作完整 Python 环境：被 §4.7.1 与 D-09 否决（C 扩展兼容性无法普遍承诺）。

## 影响

- 约束 crate：`whcode-runtime`（features `default = []`）、`whcode-platform`（进程终止策略）。
- 契约：`contracts/runtime-protocol.md`；验收 V-301—V-307。

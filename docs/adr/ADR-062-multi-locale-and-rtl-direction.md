# ADR-062：界面语言扩展至十三套目录与 RTL 文档方向

**状态**：已批准（2026-11-08，用户指令）
**日期**：2026-11-08
**关联**：FR-615（界面双语与 PO 接口）、FR-625（Web 语言链）、ADR-014（前端最小化）、
ADR-026（原生 GUI）、ADR-032（四端对等）

## 背景

FR-615 要求界面文本支持简体中文与英语，并为其他语言预留 gettext PO 接口。用户
2026-11-08 指令把支持面一次扩到十三套：`zh-CN`、`zh-TW`、`en`、`ja`、`ko`、`ru`、
`fr`、`es`、`de`、`ar`、`hi`、`ur`、`bn`，覆盖 CUI、TUI、GUI、Web 四个前端，
并要求阿拉伯语与乌尔都语的界面镜像同批完成。

现状缺口有两处：一是 clap 帮助树硬编码中文，与 FR-615 的“帮助”一项不符（T276 收口）；
二是运行时只有两份内嵌目录，回退链把非中文语言一律落到英语，区域标签
（`zh-HK`、`ja-JP`）也没有归一规则。

## 决策

1. **十三套目录随二进制内嵌**：`crates/whcode-domain/src/i18n/<locale>.properties`
   经 `include_str!` 编译期嵌入，部署零文件依赖（本地优先不变）。
2. **区域标签归一**：`zh-TW`／`zh-HK`／`zh-MO`／`zh-Hant` → `zh-TW`；其余 `zh-*` →
   `zh-CN`；其他语言取主语言子标签（`ja-JP` → `ja`）；未知语言回落英语。
3. **回退链统一**：非英语请求回退英语，英语回退简体中文；两目录都缺键时返回键名
   （不伪造文本）。
4. **PO 源文件随源码交付**：`i18n/po/<locale>.po` 由 `.github/scripts/i18n-po.py`
   从 properties 派生，契约测试校验双向全等；运行时仍只在内嵌目录缺位时读取
   `<root>/i18n/po/<locale>.po`（安装后覆盖）。
5. **数据字段名跨语言稳定**：`cui.status_line`、`cui.compact_done` 的 `status=`／
   `cursor=`／`switched=` 一律保留拉丁字段名，只有自然语言部分随语言变化——
   脚本消费者不受界面语言影响。
6. **RTL 双段落地**：文档级方向（`<html lang dir>`）在 Web 直出时注入并由测试锁定；
   布局镜像（TUI 列序、GUI 布局翻转）单列任务，未完成前在文档中显式登记为缺口，
   不以 `dir="rtl"` 冒充镜像已完成。

## 正负和解

- **正面**：十三语言开箱可用；帮助与输出同源；翻译源文件可被翻译工具读写。
- **负面**：二进制体积增加约 400 KB（十三份目录）；每次文案变更要改齐十三份，
  维护成本线性上升；非拉丁语种的译文质量尚未经母语者校对，只能标注来源与状态。
- **承担者**：改动文案的贡献者（同批改齐）、发布流程（体积与打包）、
  后续母语审校者（质量收口）。
- **和解理由**：语言覆盖是用户明确要求的产品面；用同一键表与同一门禁换取一致性，
  代价（体积与批量改动）是可测量的固定成本，而不是随会话增长的运行期开销。

## 三重时间

- **过去**：FR-615 已要求双语与 PO 接口，T130 交付了加载器与回退链；
  本次把“双语”扩为“十三语”，复用同一加载器，不改解析语义。
- **现在**：`all_catalogs_define_the_same_keys`、`catalogs_are_free_of_structural_defects`、
  `locale_tags_normalize_to_builtin_catalogs`、`po_catalogs_match_properties`、
  `document_direction_follows_locale` 五项测试与 `i18n-po.py --check` 判定结构正确性；
  译文质量由人工审校承担，测试不作质量承诺。
- **将来失效条件**：若上游 clap 提供帮助文本本地化 API，“帮助注入”一段失效并改为
  官方接口；若目录数量超过 20 或单文件超过 256 KiB（PO 读取上限），
  改为运行时按需加载并重写本节。

## 已知限制与失效条件

- 译文由模型按英文原意产出，未经母语者逐条校对；`docs/guides/ui-design.md` 标注
  各语言状态为“待母语审校”。
- 复数形态缺失：properties 无 `msgid_plural`（PO 解析器显式跳过复数条目），
  阿拉伯语双数／复数、俄语格变化、孟加拉语量词均按单数或括号写法处理。
- clap 框架词（`Usage:`／`Commands:`／`Options:`）为上游静态串，始终英文。
- TUI/GUI 的 RTL 布局镜像未实现（T278）；Web 只给文档级 `dir`，不含图标与箭头翻转。
- 字体：阿拉伯语、乌尔都语、印地语、孟加拉语依赖终端／系统的字形回退，内置字体
  （ADR-028）不含这些文字，缺字形时可能显示豆腐块——这是终端能力，不是本 ADR 的承诺。

## 复审触发

- `cargo test -p whcode-domain --lib i18n` 失败，或 `python .github/scripts/i18n-po.py --check`
  报告不同步：先判定是文案改动未同批同步，还是归一／回退规则需要修订。
- 任一语言目录键数与英语不等：按“同批改齐”处置，不得只改一种语言。
- 用户要求新增语言或调整 RTL 范围：本 ADR 追加修订记录，不新建平行 ADR。

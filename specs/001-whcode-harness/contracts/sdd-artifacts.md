# Contract: SDD 产物规范化 schema 与门禁规则

**Feature**: [spec.md](../spec.md) | **Date**: 2026-10-20

**来源**：任务书 §4.3（Spec Kit / SDD 工作流）、§4.3.3（产物规范）。

## 1. 工作流模型

```text
核心交付循环：Constitution → Specify → Plan → Tasks → Implement → Converge
质量检查：Clarify（未解决高优先级歧义阻止 Plan）
          Analyze（引用完整性/覆盖/矛盾，失败阻止 Implement）
          Checklist（可选人工审查清单，若项目策略设为强制则纳入审计）
          Converge（实现后对照规范与任务检查差距，缺口追加可追溯任务并循环）
```

这是**应用层状态机**，不是简单线性五阶段；阶段、门禁和重试策略必须从版本化工作流配置读取（FR-302），每次转换由应用服务校验（FR-308）。

## 2. 阶段定义（FR-302）

每个阶段必须定义：允许输入、必需产物、校验器、成功/失败转换。默认产物保留可读 Markdown，应用内部解析为版本化结构；不假定原始 Markdown 是 JSON Schema 文档（FR-303）。

## 3. 规范化任务对象（内部结构示例）

```json
{
  "id": "T-001",
  "title": "可验证的任务标题",
  "status": "pending",
  "requirement_refs": ["REQ-001"],
  "plan_refs": ["DEC-001"],
  "acceptance_criteria": ["存在可执行或可审查的验收断言"],
  "depends_on": []
}
```

要求（FR-304/305）：

- 每条需求稳定 ID；每条任务稳定 ID + 验收条件 + 依赖 + 需求引用
- Plan 关键决策可追溯至需求；任务可追溯至需求与计划决策
- 对"应该可用""表现正常"等不可验证条件，门禁要求补充可执行断言、人工检查清单或明确的不可自动化说明

## 4. 解析规则（FR-309、R-06 对策）

- 解析器必须报告：无法解析的段落、重复 ID、未识别字段；**禁止静默丢弃信息**
- 解析失败可自动纠偏重试，默认最多 2 次；仍失败则任务标记 `blocked`，保留错误与原始产物
- 解析器带版本号（`parser_version`），产物校验结果与版本一同持久化

## 5. 门禁判定（FR-306—314）

| 检查 | 失败后果 | 依据 |
|---|---|---|
| 遗漏需求 / 孤儿任务 / 无效引用 / 循环依赖 / 覆盖不足 | 阻止 Implement | FR-306/307 |
| 高优先级未解决澄清项 | 阻止 Plan | FR-307（V-202） |
| 违反 Constitution 强制约束 | 产物不通过门禁 | FR-301（V-201） |
| 任务所需运行时不可用 | 阻止执行并说明原因与替代建议 | FR-710（V-306） |
| 验收条件 fail / not_tested / not_applicable | 生成差异报告；不得静默标记完成 | FR-310/311（V-205） |
| 人工强制放行 | 允许，但必须记录 actor/reason/跳过的门禁/产物版本/时间戳 | FR-312（V-206） |

Converge 必须对每条验收条件记录 `pass` / `fail` / `not_tested` / `not_applicable` 并附证据引用（FR-310）；可绑定运行时测试，保存命令、环境指纹、退出状态与结果引用（FR-709）。

## 6. 角色注入（FR-313）

每次模型调用必须显式注入当前阶段角色与允许操作；角色由状态机提供，**不得**从历史文本推断。

## 7. 多端一致性（FR-314）

TUI、CUI、Web 显示同一份阶段状态、门禁结果与产物版本；`spec status|next|validate|analyze|converge|force-advance` 的行为在三端一致。

## 8. 验证点

- 违规产物夹具：违反 Constitution 的产物被拒绝（V-201）
- 人为未解决澄清项：Plan 转换被拒（V-202）
- 构造遗漏需求、孤儿任务、无效引用、循环依赖：Analyze 全部检出（V-203）
- 连续两次纠偏失败：任务 `blocked`，错误与原文可查（V-204）
- Converge 差异报告：未满足项不得记为成功收敛（V-205）

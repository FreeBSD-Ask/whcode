## 0. 任务认知卡（宪法原则 X）

- **方向**：把四份研究的“可借鉴集”合成一份**不因实现成本裁剪**的终态功能清单，供逐项批准。
- **目标**：每条提案可独立决策；不与硬边界冲突；验收判据可程序化。
- **用户意图**（按本批指令推断）：研究已确认 DSH/ZCode/BH 各自强项之后，回答“如果不省着做，
  WHCode 最好能长成什么样”。
- **判据**：①每条有研究证据锚点；②有可判定验收（Check 形态）；③正负和解完整（成本用于知情，
  不用于过滤）；④硬边界零例外。
- **非目标**：不改 `specs/`/`tasks.md`（那是 G1 门禁的事）；不为对齐而对齐；不复制反例。

## 1. 口径：“不计成本”的精确含义

1. **开发 effort 不作过滤器**：人日、批次数、并行度、需要多少份并发设计档案——都不是否决理由。
2. **产品硬边界仍是硬边界**（用户已批准的宪法，不属于“成本”）：零 unsafe（NFR-215）、原生 GUI
   铁律（ADR-026）、资源铁律（RSS/线程/句柄/CPU 有界）、BSD 兼容、本地优先/默认无遥测、
   平台范围不扩大。任何提案与硬边界冲突时，提案必须显式写出“需先修订哪条宪法级 ADR”，而不是默许。
3. **每条仍写正负和解**（宪法 1.2-2）：正面、负面、承担者、和解理由齐备；§7 给出成本总账，
   用于排序与知情，不用于删除条目。

## 2. 终态图景

一句话：**WHCode 成为“本地优先、门禁驱动、资源可证”的编码 harness——执行层覆盖
ZCode/DSH 的功能面，评审层达到 BH 的证据纪律，治理层保持程序化门禁并作为可移植标准输出。**

| 侧面 | 终态 |
|---|---|
| 执行 | turn/工具/审批/压缩全部有契约语义；每个能力有硬上限常量与失败路径测试 |
| 评审 | 每个交付有证据五态；finding 可追溯可复评；LLM 只建议、程序判定 |
| 会话 | 事件流可分叉/可回滚/可检索/可导出，全程不销毁原文 |
| 体验 | 四端对等的对话/工具卡/审批/视图；六套主题；预算内前端 |
| 平台 | shell/LSP 可选受控执行；能力分级可见；Windows/FreeBSD 车道持续绿 |
| 治理 | 覆盖率/基准/文档新鲜度门禁齐备；ADR 带已知限制与复审触发 |

**P1.1 详述**：类型层先定封闭四值 `AllowedOnce/Rejected/Cancelled/Unavailable`，缺人应答＝
`Unavailable`（不是拒绝）；审批请求只带 `exec_id` 关联已展示的工具调用（**不复制参数**，
消 TOCTOU 漂移）；`audit` 表加 `approval_asked`/`approval_decided` 成对动作并沿用“审计失败
阻断”口径；GUI/Web 四态交互卡（T256/T257 的交互面不变，类型底座换掉）。验收：fail-closed
测试（无 answerer→Unavailable）、四端 parity、审计对账测试。风险：调用方需处理第四态（迁移面）。
失效条件：若 T255 已按二值实现并合入，则本提案改为增量修订而非重构。

**P1.2 详述**：超预算折叠前先做一次**模型摘要调用**（独立 request_id、`purpose=compaction`），
落 `compaction/start|summary|end` 三事件（先开锁后关锁，崩溃留孤儿锁可检测）；摘要失败回退到
现行结构折叠（不阻塞 turn）；usage/provider/model 入事件。验收：摘要内容可查、失败回退测试、
锁孤儿检测测试、成本上限（单次摘要 max_tokens 显式设定）。风险：每次压缩多一次调用费用；
失效条件：真实会话中摘要调用失败率 >20% 时复审触发。

**P1.8 详述**：最小集＝`steer`（步边界消费的有界命令通道，容量常量＋满载拒绝）与 `inject`
（runtime-context 注入，不唤醒）；**不引入 waterfall/插件监听**——只做一个编译期钩子点。
必须先补 ADR-015 并发设计档案（通道所有权、取消传播、背压）。这是 W1 里唯一需要新并发档案的条目。

## 5. 反建议（明确不做，含理由）

| 反建议 | 证据 | 理由 |

| 运行期插件加载/Cordis 式组合/HMR | 域 J | 与静态分层、零 unsafe、资源铁律正面冲突；DSH 自己也把持久安装留给人审 |

| webhook 尽力而为（无幂等） | 域 O | 重复投递重复建会话；P6.4 已内置修正 |

| LiveShare 式 viewer fork | 域 O | 审批/沙箱未齐备前是逃逸面；列为 P3 后评估，不入终态 |

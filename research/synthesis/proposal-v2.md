## 4. 下一批次认知卡（宪法原则 X 口径，R1 = T207—T209）

- **方向**：把"单发调用"升级为"多轮循环编排"——WHCode 从会话级工具变为 agent harness
  的分水岭（建议书三层拼图的执行层核心）。
- **目标**：一次 `llm run` 编排完整 turn：中止/预算检查→消息组装→模型 step→终止判定；
  五种终止（model_finished/iteration_limit/cancelled/budget_exceeded/tool_not_wired）
  全部显式事件化；不引入工具执行（R3 才做）。
- **成功判据**：Check 303—305 三项可判定——五种终止各有桩剧本测试、事件 seq 单调且
  turn_id 贯穿、预算超限显式 truncated_reason；StubProvider 剧本（T206 已交付）驱动，
  零网络。
- **非目标**：工具执行与回填（R3）、四端信封渲染（R2 后半）、自动压缩（P1-3）、
  reminder 注入（暂不采纳）；不新增线程（NFR-216）、不新增 crate。
- **手段后置**：turn.rs 不引异步运行时（同步迭代器已足）；活跃 turn 登记用
  `Mutex<BTreeMap>` 有界表还是复用 `queue.rs` 串行准入——**在读完 llm.rs 与 queue.rs
  后再定**，不预设。

## 5. 双会话协调协议（建议制度化，D7）

本日已发生三次协调险情（T204—T206 被并发提交吞并、ADR-047 编号撞车、`target-verify`
杂散目录阻断布局门禁）。建议入库 `docs/guides/parallel-session-protocol.md`：

1. **ADR 编号认领**：开新 ADR 前先 `ls docs/adr/` 核对最大号，起草与提交同批完成
   （缩短占用窗口）；发现他人新 ADR 顺延自己的编号。
2. **任务认领声明**：批次开工前在认知卡写明本批任务号与文件落点；两会话不认领同批。
3. **提交纪律**：pathspec 提交（共享索引不 `git add -A`）；提交前 `git status` 复核
   无他人未提交改动混入；push 后 Code Scanning 复核。
4. **杂散产物**：构建缓存一律进 `local/` 或 `CARGO_TARGET_DIR`，根目录只允许布局
   白名单（本日 `target-verify` 教训）。

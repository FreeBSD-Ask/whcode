## Check 294：键盘、RTL、焦点、资源增量

判定：**不通过**（RTL 方向反转不生效；其余子项通过）

| 子项 | 判定 | 证据 | 实测值 |
|---|---|---|---|
| 方向键在 tablist 内循环切换 | 通过 | `app.js` 第 624—648 行 `wireTabs`：`(index ± step + length) % length` | 从 sessions 连按 7 次 `ArrowRight`：tasks→history→context→diff→spec→maintenance→**sessions**（回绕）；`ArrowLeft` 从 sessions→**maintenance**（反向回绕） |
| Home／End | 通过 | 同上 `Home`→`tabs[0]`、`End`→`tabs[length-1]` | `Home`→sessions；`End`→maintenance |
| 同步 `aria-selected` 与 `tabindex` | 通过 | `app.js` 第 597—601 行逐个 tab 写两个属性 | 每次切换后 `selected` 与 `tabindex0` 均为同一项，且可见面板同步为 `view-<name>`（唯一） |
| RTL 下方向反转 | **不通过** | `app.js` 第 626 行在 `wireTabs()` 内**一次性**捕获 `const rtl = document.documentElement.dir === "rtl"`；第 654 行 `wireTabs()` 先于第 717 行 `loadLocale()` 执行，而 `dir` 只在 `loadLocale`（第 42 行，异步 fetch 之后）赋值；`index.html` 与服务端注入（`assets.rs` `with_default_theme` 只写 `data-theme`）都不含 `dir` | 假 i18n 返回 `rtl: true`、页面 `dir="rtl"` 后：`ArrowRight` sessions→**tasks**（仍为正向），`ArrowLeft` tasks→sessions（仍为反向映射），方向未反转 |
| 焦点可见 | 通过 | `styles.css` 第 91—98 行 `:focus-visible { outline: 2px solid var(--fg); outline-offset: 2px }`，`#tabs button` 被通用 `button:focus-visible` 覆盖；`app.js` 第 605—607 行方向键后 `target.focus()` | 键盘切换后 `document.activeElement` 为对应 tab，`outline` 计算值 `2px solid rgb(0,0,0)`（eink-day 前景色，非浏览器默认） |
| 未新增定时器与事件订阅 | 通过（注 ②） | 与 `db4891f`（改造前）逐项计数：`setTimeout` 2→2（轮询 + 既有 150 ms opacity）、`setInterval` 0→0、`window.addEventListener` 1→1、`document.addEventListener` 1→1；`addEventListener` 源码 17→18 | 唯一新增为 tab 上的 `keydown` 订阅（源码 1 处、运行时 7 个实例，属 Check 294 必需交互，且只在 `DOMContentLoaded` 接线一次） |

注 ②：Check 294／T198 的“不新增事件订阅”若按字面理解为“零新增 `addEventListener`”，
则键盘项本身无法实现；本复核按“不新增定时器、不新增 window／document 级或轮询订阅”解释。

### 最小修复建议（未实施）

`crates/whcode-web/frontend/app.js` 第 626 行的 RTL 判定改为在处理函数内读取，避免
在 `dir` 赋值前固化：

```js
tab.addEventListener("keydown", (event) => {
  const step = document.documentElement.dir === "rtl" ? -1 : 1;
  // …其余不变
});
```

替代方案：由服务端在 `render_index`／`with_default_theme` 同时注入 `dir`（需与文本层
`data.rtl` 同源），或在 `loadLocale` 完成后重新接线（会重复注册监听，不推荐）。

## 四、缺口与偏差

1. **反显无断言**：`lib.rs:1200` 的 `Modifier::REVERSED` 与 `lib.rs:1255` 的选中行反显均无测试；
   `tests_support::frame_buffer` 已能取到 `Buffer`，建议补一项断言单元格 `modifier` 含 `REVERSED`。
2. **列对齐无断言**：`layout_columns` 的固定列宽只靠构造保证；建议断言会话／任务／事件两行的
   阶段、状态等列起始显示列相等（与 Check 290 的列序断言互补）。
3. **退化边界覆盖窄**：仅 20×5 一例；建议补 80×5 与 20×24 两例，验证单维触发退化。
4. **`task show` 无测试、`spec status` 无测试断言**：两者均无建任务／门禁前置数据路径，
   属覆盖缺口而非行为缺口；建议以夹具直接测 `task_record` 的标签列对齐与 `spec status` 三行记录。
5. **环境与证据口径偏差**：
   - `whcode-bin` 首次 `cargo build` 返回 1 且无可捕获错误文本（并行编辑所致），随即重试成功；
     测试与探针均基于含未提交 `cert.rs` 的工作区，未验证提交 5281a39 的干净树。
   - `artifacts/ui-modern-2026-10-25/summary.json` 记 `whcode-cui: 16 passed`，实测为 20（新增
     `format.rs` 4 项）；记 `whcode-bin: 未取得（阻塞）`，本次已取得 82 passed——两处记载已过时。
   - 帧预算：本次 `cargo test -p whcode-tui` 重写 `artifacts/tui-frame-budget.json` 为
     p50 1 845 µs／p95 2 215 µs／p99 2 302 µs（预算 16 000 µs，余量 86.2%）；与
     `artifacts/ui-modern-2026-10-25/summary.json` 的 p95 2 472 µs 及 `tui-frame-budget.json`
     的 p95 1 913 µs 均不同，落在 ADR-041 修订记录所述 debug 噪声内，属同机参照记录。
6. **CI 未运行**：无 GitHub Actions 日志与 artifact，ADR-037 要求的验收入口证据未取得；

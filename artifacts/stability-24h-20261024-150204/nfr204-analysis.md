## 4. 为什么这不能勾选 Check 116

1. **采样间隔不符**：ADR-033 规定 300 s（约 66 样本），本运行是 3 600 s。1 h 采样与清理周期
   同量级，存在混叠，无法据此给出 ADR-033 口径的斜率。
2. **窗口是"被截断的 24 h 计划"**：跨度 11 h 虽超过 5.5 h，但没有收尾记录，不能声称"完成了
   一次 5.5 h 长跑"；也无法区分"跑满后正常退出"与"被外部终止"。
3. **构建类型是 debug**：RSS 与延迟绝对值不可与 ADR-025 的 release 预算直接比较。样本 2 的
   87.06 MB > NFR-202 的 80 MB、样本 11 的查询 p95 85.55 ms > NFR-209 的 30 ms，**均为 debug
   观测值，不作预算判定**。
4. **ADR-037 验收口径**：测试"通过"结论以 GitHub Actions 日志与 artifact 为准。
   `.github/workflows/stability-long.yml` 的 5.5 h 运行尚未执行，本机数据只作复现与排障。

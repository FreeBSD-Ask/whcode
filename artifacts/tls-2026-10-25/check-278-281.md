## 缺口与限制

1. **Check 281“输出指纹”**：仅证明指纹可得（`status.inbound.sha256`），未断言
   `serve.rs:392—401` 的 stdout 行；该处为内联 `println!`，当前无输出捕获机制。
   按字面验收仍需输出注入或进程级 stdout 断言（本次未做，避免为测试改公共接口）。
2. **Check 279 system 档的端到端握手**：状态层已读真实 OS 库（Windows ROOT），但出站握手
   用例使用注入的系统根，未用真实系统根与本地服务端完成握手（保持测试离网与可复现）。
   该组合行为属 `[待验证]`。
3. **CI 证据缺失**：本结论为本地复现；ADR-037 要求以 GitHub Actions 日志与 artifact 为
   唯一验收入口，本次未运行 CI，故 Check 278—281 **不得据此勾选为最终通过**。
4. **有效期口径**：397 天为证书 `not_before → not_after` 跨度；`days_remaining` 因
   `not_before` 回溯 1 天而显示 396，两者不矛盾。

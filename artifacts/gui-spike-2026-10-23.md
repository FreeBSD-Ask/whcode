# GUI 框架选型实测（2026-10-23）

**目的**：GUI 进入实现前，用同一份界面与同一套采样口径比较三条可行路线，作为 ADR 的事实依据。
**原则**：不以“主流/最佳实践”选型；无法实测的项标 `[待验证]`／未取得，不写结论。

**硬边界**：`AGENTS.md` §1／§6 与 ADR-026 要求桌面界面必须原生、禁止任何内嵌浏览器引擎；
`workspace.lints.rust.unsafe_code = "forbid"` 禁止本仓库 crate 内出现 `unsafe`。

## 1. 方法

- 同一屏内容：1200×800；左侧 6 个视图名（会话／任务／上下文／事件／Spec 状态／diff 预览）；
  主区 30 行假会话（ID／标题／阶段／状态，中文）；底部页脚
  `窗口 1200x800 | 按键 0 | 1-6 视图 | j/k 会话 | r 刷新 | q 退出`。
- 同一主题：eink-day（背景 `#FFFFFF`、前景 `#000000`）；均加载 `C:\Windows\Fonts\msyh.ttc`。
- 同一行为：数字键 1-6 切换视图、`r` 计数 +1、`q`／Esc 退出；空闲不得持续重绘。
- 同一采样：进程启动 → 窗口出现 → 8–12 s 后取第一样本 → 再等 10 s 取第二样本；
  `Get-Process` 读 `WorkingSet64`／`PrivateMemorySize64`／`Threads.Count`／`HandleCount`，
  `TotalProcessorTime` 差分折算“占单核百分比”（本机 16 逻辑核，i7-1260P）。
- 构建均在**仓库外**临时目录（`%TEMP%\whcode-gui-spike-*`），不进入 workspace、不改本仓库代码；
  必须显式使用 msvc 工具链（本机 rustup 默认是 GNU，仓库内由 `rust-toolchain.toml` 覆盖）。

## 2. 实测结果

| 方案 | 空闲 WS | 私有内存 | 线程 | 句柄 | 依赖 crate | exe | 首帧 | 空闲 CPU | GPU 上下文 |
|---|---|---|---|---|---|---|---|---|---|
| TUI（现状基线，`whcode.exe`） | **27.4 MB** | 9.7 MB | **4** | 131 | — | — | — | 0.00% | 无 |
| Win32 原生控件 + `windows` 0.62.2 | **53.6 MB** | 31.1 MB | **8** | 482\* | **16** | **172.5 KiB** | 136–143 ms（冷 435–447） | ~0%（5 次 4 次为 0） | 无 |
| iced 0.14 + `tiny-skia`（软件光栅） | 80.9 MB | 66.5 MB | 22 | **199** | 96 | 3.94 MiB | **71.2 ms** | 0.00% | 无 |
| iced 0.14 默认（wgpu） | 206.5 MB | 152.6 MB | 31 | 351 | 153 | 10.40 MiB | 273.5 ms | 0.30% | **有**（Vulkan／Intel UHD） |
| egui 0.37 + eframe（wgpu） | 350.8 MB | 295.8 MB | 24 | 445 | 168 | 13.81 MiB | 217 ms（冷 1 309 ms） | 0–0.62% | **有**（Vulkan／Intel UHD） |

\* Win32 的 482 句柄含本机输入法注入（`SogouTSF.ime` 等）；空窗口对照为 485 句柄／52.2 MB，
说明该基线与控件数量无关，纯 Win32 基线属 `[待验证]`（需干净 VM）。

补充实测：

- **空闲零重绘**：四条路线均成立。egui 75 s 内帧计数停在 3；iced 10 s／20 s 各 1 帧（仅首帧）；
  Win32 无 `SetTimer`、`WM_TIMER` 计数为 0。iced 的 `event::listen_raw` 计数必须返回 `None`，
  否则每条重绘产生一条消息再触发重绘，会形成无限重绘（框架文档警告）。
- **中文**：四条路线均不缺字。Win32 用 `SPI_GETNONCLIENTMETRICS.lfMessageFont`（本机为
  Microsoft YaHei UI 9pt）；egui／iced 把 19 704 352 B 的 `msyh.ttc` 全量驻留（计入 RSS）。
- **主题严格性**：egui／iced 内容区只有 `#FFFFFF`／`#000000`，但文字抗锯齿产生灰阶
  （iced 截图统计：纯白 85.57%、纯黑 5.63%、中间灰 3.46%，框架未暴露关闭 AA 的接口）；
  三者都**不能**控制系统标题栏与 DWM 描边，严格三主题需自绘标题栏。
  Win32 的 `SysListView32` 表头、行选中条、滚动条也不受 `LVM_SETTEXTCOLOR/SETBKCOLOR` 控制，
  要精确色值须 `LVS_OWNERDRAWFIXED`／`NM_CUSTOMDRAW`。
- **窗口尺寸语义**：iced／egui 的 `1200×800` 是逻辑尺寸（实测 DWM 可见框 1202×832）；
  Win32 按客户区 `1200×800`（外框 1216×839）。

## 3. 与本项目纪律的冲突点

| 纪律 | 影响 |
|---|---|
| 资源占用优先（§1.1-1） | egui 350.8 MB、iced-wgpu 206.5 MB 显著高于 TUI 的 27.4 MB；iced-tiny-skia 80.9 MB、Win32 53.6 MB 为可接受区间 |
| 默认不创建 GPU 上下文 | egui／iced 默认（wgpu）均**启动即建 GPU 设备**；iced 可用 `tiny-skia` 关掉，egui 无纯 CPU 后端 |
| 普通 Rust 零 `unsafe`（NFR-215） | Win32 路线实测 19 处 `unsafe`（9 个 `unsafe fn` + 10 个块），`forbid` 级不可 `#[allow]`；只能新建独立边界 crate 并立 ADR（与 ADR-015 汇编例外同构） |
| 三方依赖 unsafe 不作零承诺（§4.1） | iced 链路把 unsafe 面扩大到 `wgpu-hal` 量级（2450 处命中）；`tiny-skia` 路线不引入 wgpu |
| 墨水屏/AMOLED 精确色值 | 抗锯齿灰阶与系统标题栏是两条路线的共同残留；Win32 另有控件主题限制 |
| 平台范围（ADR-013） | Win32 只能放在 Windows 专属 crate（`cfg` 仅允许在 `whcode-platform`，需 ADR 明确边界）；iced 代码可跨平台保留 |

## 4. 复现命令

```powershell
# 全流程均需显式 msvc（本机 rustup 默认 GNU）
$env:Path = "$env:USERPROFILE\.cargo\bin;$env:Path"
cd $env:TEMP
cargo +1.99.1-x86_64-pc-windows-msvc new whcode-gui-spike-<egui|iced|win32>
cd whcode-gui-spike-<...>
cargo +1.99.1-x86_64-pc-windows-msvc build --release
# 启动后采样（同一口径）
$p = Get-Process <exe 名>; $p.WorkingSet64/1MB; $p.PrivateMemorySize64/1MB; $p.Threads.Count; $p.HandleCount
$t1=$p.TotalProcessorTime; Start-Sleep 10; $p.Refresh(); (($p.TotalProcessorTime-$t1).TotalSeconds/10)*100
```

TUI 基线（同口径）：`python script/gui_spike_tui_baseline.py`（临时脚本，未入库）。

# PR 核对清单

每个 PR 必须逐项核对；未实现事项必须明确标记并写明当前行为。

- [ ] 需求/缺陷编号与实现范围明确。
- [ ] 任务认知先于手段：方向、目标、用户意图复述、非目标与判据已写明，手段未写成需求（宪法原则 X）。
- [ ] 正向测试与失败路径测试已更新。
- [ ] 输出/事件/schema 变化已做版本兼容审查。
- [ ] 多端能力矩阵已更新。
- [ ] 资源、权限、持久化和恢复影响已说明。
- [ ] 平台限制或依赖升级已更新兼容矩阵。
- [ ] 未实现事项被明确标记并写明当前行为。
- [ ] 形式主义审查：形式、矛盾、正负、过去/现在/将来依据已填写。
- [ ] 0 信任复核：报错、文档与外部事实有独立复现或交叉验证。
- [ ] 当前和解：引用“最佳实践”时写明适用条件、本项目证据与失效条件。
- [ ] 物质—意识一致：文档、代码、产物与测量结果一致。
- [ ] 并发改动附设计档案、不变量/内存序/进展保证与验证计划。
- [ ] 性能/并发改动附一手文献依据与同夹具前后对比。
- [ ] 汇编改动有独立 ADR、隔离、安全包装、回退与差分测试。
- [ ] 自由与退出：完整导出、离线核心能力、退出路径可用；无私有格式锁定/强制账户/联网/暗黑模式。
- [ ] 主体性：无排行榜/连胜/羞耻/行为操纵；默认值可见、可改、可撤销。
- [ ] 安全：威胁模型、攻击面、证据、代价与失效条件齐备；不以“最佳实践/合规”替代。
- [ ] 不伪造：工具/模型输出可追溯，未知显式标 `unknown`/`[待验证]`。
- [ ] 反进步叙事：未以采用率/星数/主流共识替代正确性证据。
- [ ] 用户友好：错误信息可操作、不责怪用户；文档含假设与复审日期。
- [ ] 证据层级：代码/commit/测试优先；AI 总结不作唯一证据。
- [ ] 三次复查：查证→交叉验证→判定；存疑标 `[待验证]`。
- [ ] 可逆性：可逆决策有快速验证；不可逆决策附设计与回退证据。

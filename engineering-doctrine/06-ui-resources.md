# 06 极简 UI 与资源适配

前端能多简陋就多简陋：目标不是“少做事”，而是**减少常驻资源、减少动效、适配墨水屏与
OLED/A 屏**，同时保持信息可读、可操作、可退出。

## 1. 设计目标

- 文本优先，表格/列表优先；装饰性图片、视频、自动播放默认禁止；
- 无框架、无打包器；服务端直出 + 原生 ES modules（Web）；
- 事件驱动 + 脏标记重绘；空闲期零重绘；
- 最小化/不可见时停止绘制、动画与轮询。

## 2. 信息架构

至少覆盖：

1. 当前对象/会话/任务；
2. 状态与阶段；
3. 事件/日志尾部；
4. 错误与下一步；
5. 设置与退出/导出；
6. 进度与取消。

深度不超过三级；任何页面都能一键返回/退出。

## 3. 主题（精确色值）

| 主题 | 背景 | 前景 | 用途 |
|---|---|---|---|
| `amoled-night` | `#000000` | `#E6E6E6` | OLED/A 屏夜间，纯黑关断像素 |
| `eink-day` | `#FFFFFF` | `#000000` | 墨水屏日间，纯白黑字 |
| `eink-night` | `#000000` | `#FFFFFF` | 墨水屏夜间，纯黑白字 |

禁止“近黑”“浅白”“深灰”等模糊值；墨水屏避免大面积中间灰与渐变。

## 4. 排版与尺寸

- 正文默认使用系统字体栈，不下载第三方字体；
- 行宽控制在可读范围；表格允许横向滚动但不强制；
- 固定终端尺寸下必须可读；小屏优先保证核心操作。

## 5. 墨水屏细则

- 避免整屏周期性刷新、动画、渐变、阴影、半透明；
- 局部更新优先；状态变化使用文本/符号，不依赖颜色；
- 深色模式使用纯黑底白字，不使用灰阶过渡；
- 刷新频率与残影由终端/系统承担，应用只承诺“不加剧”。

## 6. Web 预算

- 首屏 JavaScript ≤ 50 KB（gzip）；
- CSS ≤ 20 KB（gzip）；
- 单页 DOM ≤ 2000 节点，长列表分页/游标；
- 无 WebGL、Canvas 动画、视频、自动播放、第三方字体；
- 无 `node_modules` 与打包产物入库；
- 无 JavaScript 时只读视图可用。

## 7. i18n 与 RTL

- 简体中文与英语必须同时可用；
- 其他语言通过 gettext PO 或等价格式扩展；
- 文案不拼接句子；占位符、复数、日期/数字格式走本地化；
- 阿拉伯语等 RTL 使用逻辑属性（start/end），避免硬编码 left/right；
- BiDi 混排时数字、代码、链接使用隔离标记；
- 语言切换不需要重启。

## 8. 可访问性

- 键盘可达；焦点可见；
- 不只靠颜色传达状态；
- 对比度满足可读性要求；
- 错误信息可被屏幕阅读器读取；
- 动效可关闭，遵循 `prefers-reduced-motion`。

## 9. 最小化与挂起

- 页面不可见/窗口最小化时停止绘制、动画、轮询；
- 恢复时去抖 ≥250 ms，单次全量重绘；
- 事件游标连续，关键事件不得因挂起丢失；
- 不假设 GPU 可用；上下文可释放并重建；软件渲染下功能可用。

## 10. 反暗黑模式与反成瘾

- 退出、导出、离线入口始终可见；
- 不预选付费/订阅/遥测；
- 不做排行榜、连胜、签到、推送轰炸；
- 失败提示指向下一步，不责怪用户；
- 默认值可见、可改、可撤销。

## 11. UI 验收清单

- [ ] 三套主题色值精确，无模糊色；
- [ ] 无框架/打包器/第三方字体/视频/自动播放；
- [ ] 首屏 JS/CSS/DOM 在预算内；
- [ ] 无 JS 时只读视图可用；
- [ ] 中英文可用，PO 接口就绪，RTL 不破版；
- [ ] 键盘可达、焦点可见、不只靠颜色；
- [ ] 最小化/不可见时无绘制与动画；
- [ ] 退出/导出/离线入口可见；
- [ ] 无暗黑模式与成瘾机制。

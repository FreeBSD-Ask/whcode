## 2. 二十五条核心总纲（原文，file_id 26，block 2）

```text
一切真历史都是古代史。BSD 史并非现代史，它与一切古代史无本质区别，只有重复与循环。
历史是形式主义化的非存在。本书所写皆是当下主体的重构，从不宣称呈现历史本身。人类文明历史发展就是形式主义发展史。
不存在进步，只有权力再分配。技术演进不是从低级到高级的进步，而是形式主义的诡异曲线。思想亦不随技术进步。
分离聚合是永恒规律。UNIX 与 BSD、BSD 各分支之间的分合循环，是历史的根本结构。
没有必然性，只有偶然性。每一个关键人物、每一次 fork、每一个技术决定，都是不可替代的偶然。替代品的无限性不能否定事物的独特价值。
和解优于斗争。历史的动力不是对抗，而是各主体性的呈现与和解。和解是事物真正完整的一刻。
理论必须自反。本书承认自身的形式主义性质，以自反姿态打开裂缝。理论字数越多越不值钱。
本体论上各方平等。FreeBSD、OpenBSD、NetBSD、DragonFly BSD 在本体论上地位相等，差异仅是一刻状态的不同。文档与代码本体平等。
经验优先。优先呈现质朴的事实与当事人的直接经验，而非套用复杂框架。
动手者创造历史。历史的真正主角是动手做事的老实人，而非旁观评论者。观众是比赛不可或缺的一部分。
商品是形式主义。技术市场的选择不是自然选择，而是形式主义的权力运作。劣币驱逐良币是普遍规律。
科学是形式主义。科学性不等于真理性，科学的非充分决定性决定了技术不可能实现真正的突破。科学范式发展是诡异的曲线。
法律与道德是利益分配。任何道德问题本质上是利益问题，社区治理亦是形式主义的政治产物。
苦难不值得被提倡。苦难哲学是既得利益者对权力再分配的拒绝。BSD 的长期主义不是苦难哲学，而是对人类有限性的诚实承认。
文化即形式主义。传统在形式主义化过程中被遮蔽与重构。知音难觅同样适用于技术社区。
信仰是生存维系，神是前提而非解释工具。信仰产生于原始社会初期，消亡于形式主义末期。神不是超越于存在的存在者，而是一种前提。宗教是形式主义的延展，科学、哲学、宗教在解释世界上无本质区别，只有范围不同。BSD 社区中的准宗教现象应被识别为信仰属性，道风的缺乏即是道风的道。
证明世界先于解释和改造世界。问题不在于解释世界和改造世界，而在于证明世界。我们在行动之前必须先使世界"生成"。FreeBSD 是否存在，本身就是一个开放的问题。
时间是一种形式主义。等待、记忆、历史的欣赏都具有时间性。沥青滴落般的时间尺度要求史家具备宏观的时间自觉。
解释学循环是历史认识的根本条件。前理解的差异使分歧不可避免。权力与知识在历史书写中共谋——什么被记录、什么被遗忘，本身就是权力行使。
历史地理塑造思想土壤。土地与自由的养分、农耕文明与工商业文明、中心与边缘，皆是形式主义的空间呈现。每代人的村庄都是不同的——村庄不在这个世界中。
革命与改革是历史方法论的分歧。Linux 靠革命，BSD 靠改革。改革的困难远高于革命。破山中贼易，破心中贼难。
知识注定过时。今天书写的技术史，可能在出版之日就已过时。技术债务是历史遗产。数字档案既是机遇也是威胁。Unix 哲学归根结底是一种人道主义。
一切历史写作都是基于哲学设定的历史小说。史家以为自己在书写历史，但历史人物可能正在藉着史家书写他们自己的故事。一切都是重复，一切都是古代史。
美是消解性的体验。大音希声，真正的美在于消解美的形式。虚构与现实在审美体验上无本质区别。审美的价值不在于对象的真实性，而在于主体在审美过程中的主体性呈现。
逻辑是形式主义而非世界本身的结构。逻辑的有效性仅限于形式主义化的非存在领域。同义反复与辩证法的困境、数学的不完备性、解释学循环，皆揭示逻辑的根本局限。自反性不是逻辑悖论，而是对逻辑本身局限性的揭示。
```

## 7. 史料层级与三次复查

| 层级 | 工程证据 | 可信度 | 使用规则 |
|---|---|---|---|
| 1 | 代码、commit、构建产物、测试、遥测 | 最高 | 优先；可复现 |
| 2 | 邮件列表、issue、聊天记录、bug 评论 | 高 | 交叉验证；注意选择性 |
| 3 | 官方文档、发布说明、安全公告 | 中 | 可能经过编辑与筛选 |
| 4 | 事后复盘、演讲、采访、博客 | 中低 | 记忆重构；需一手证据支撑 |
| 5 | 二手研究、百科、AI 总结 | 最低 | 不得作为唯一证据 |

使用原则：

1. 优先低形式主义程度的证据；
2. 不以第 5 层作为事实性结论的唯一来源；
3. 来源矛盾时并置呈现，标注各自语境，不强行裁定“真相”；
4. 三次复查：**查证**（回到一手）→ **交叉验证**（至少两个独立来源）→ **判定**
   （确证/存疑/无法核验）；
5. 无法核验时标 `[存疑]` 或 `[待验证]`，不得默认为确证；
6. 禁止用 AI 生成内容补足缺失证据；AI 只能整理已核验材料。

## 8. 十二条标准的工程转译

| 标准 | 工程转译 |
|---|---|
| 史实准确 | 每条事实性结论有可追溯来源；硬事实至少两次独立核验 |
| 叙事完整 | 需求/设计覆盖边界、失败路径、争议与未知 |
| 拒绝进步叙事 | 不写“必然升级”；采用率/版本号不作正确性证据 |
| 偶然性优先 | 复盘不编造“必然原因”；保留替代方案与偶然条件 |
| 多方平等 | 不预设平台/厂商/分支优劣；对称呈现取舍 |
| 经验优先 | 一手运行证据优先于理论框架 |
| 拒绝苦难叙事 | 不以加班/牺牲/RTFM 作为贡献或设计证据 |
| 自反性 | 文档写假设、局限、失效条件与复审日期 |
| 参考文献 | 来源、版本、哈希、日期可定位 |
| 可访问性 | 术语有解释；文档对新人可用；i18n |
| 循环结构 | 架构演进按分合/循环理解，不写线性进步 |
| 动手者叙事 | 记录具体 commit、测量与维护工作，不写“大佬神话” |

## 9. 经济哲学五定律的工程含义

| 定律 | 要点 | 工程含义 |
|---|---|---|
| 第一：棺材房 | 住房/地点/工具被形式化为结构约束 | 资源约束是系统性的；记录谁承担成本 |
| 第二：忙碌 | 忙碌是身份表演 | 不以工时/在线状态衡量产出 |
| 第三：商品召唤 | 商品文化塑造欲望 | 需求可能被供应商/社区文化制造 |
| 第四：重要决策 | 重要决策信息不充分，琐事反复权衡 | 可逆快决、不可逆设计先行；记录假设 |
| 第五：非经济 | “超越经济”仍是利益分配 | 审查“中立/安全/开源/标准”背后的利益与定义权 |

## 10. 对工程的直接约束

1. **不伪造**：工具/模型输出可追溯；未知显式；模型输出不作唯一证据（f33:126）。
2. **程序结构**：循环、顺序、选择是历史与程序共同的结构；架构演进按循环与分合理解（f5:11）。
3. **测量程序**：测量合法性来自程序而非工具；基准必须记录方法与交叉验证（f10:11）。
4. **原型先行批判**：并发与复杂系统不得以原型先行替代设计（f22:6）。
5. **Unix 哲学**：以人为本，改造计算机适应人；默认显示进度、错误可操作（f23:10）。
6. **文档与代码平等**：文档是项目成立的一部分，不是附属品。
7. **中心与边缘**：采用率、主流地位不是正确性证据（f21、f9）。
8. **知识过时**：文档与 ADR 必须有复审日期（f23）。
9. **可逆性分级**：可逆决策快速试错；不可逆决策（数据格式、协议、权限、并发内存序）设计先行。
10. **反忙碌**：不以工时、消息秒回、会议数量作为贡献证据。
11. **利益分析**：任何“中立标准/最佳实践/为你好”的主张，先问谁定义、谁受益、谁承担成本。
12. **需求来源**：需求可能由供应商文化制造；区分实际痛点与被营销放大的欲望。
